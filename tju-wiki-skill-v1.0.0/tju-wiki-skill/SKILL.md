# 天大维基查询（北洋维基 / TJU Wiki）

数据源: **北洋维基** — 天津大学校园维基（Typecho 系统），URL: https://wiki.tjubot.cn/
由天大学生维护，词条覆盖: 天大概况、招生简章、录取分数线、报到流程、军训、校历、课程与成绩、转专业、奖学金、图书馆、宿舍、食堂、校园网、考研保研、出国交流等。

## 重要前提（必读）

1. **不能用 curl / wget 抓取**：该站点对 curl 做 TLS 指纹拦截（返回 0 字节空响应）。必须使用 Python `requests` 并携带浏览器 User-Agent。辅助脚本 `tju_wiki.py` 已封装好全部请求逻辑，**优先直接调用脚本**。
2. **时效性**：词条更新于不同年份，回答涉及"最新""本学期"等时效问题时，需注意词条年份，并优先选用最新学年/年份的词条。
3. 脚本依赖 `requests` + `beautifulsoup4`（环境已预装）。

## 使用方式

脚本位置: 与 SKILL.md 同目录的 `tju_wiki.py`。先定位脚本路径再调用：

```bash
cd <skill目录> && python3 tju_wiki.py <命令>
```

## 命令速查

| 命令 | 作用 | 示例 |
|---|---|---|
| `search <关键词> [页码]` | 全文搜索词条 | `python3 tju_wiki.py search 转专业` |
| `cat <分类名或slug> [页码]` | 浏览某分类下的词条列表 | `python3 tju_wiki.py cat 图书馆` |
| `cats` | 列出全部分类（中文名+slug） | `python3 tju_wiki.py cats` |
| `read <词条URL或slug>` | 阅读词条全文（含表格/图片链接） | `python3 tju_wiki.py read https://wiki.tjubot.cn/calendar/calender-26-27` |
| `read <url> --no-images` | 阅读词条但不输出图片 | 同上加 `--no-images` |
| `latest [数量]` | 最近更新的词条 | `python3 tju_wiki.py latest 10` |
| `home` | 首页推荐词条 | `python3 tju_wiki.py home` |

## 工作流程建议

1. **定位词条**：用 `search` 搜关键词；不确定关键词时，先用 `cats` 看分类，再用 `cat` 浏览分类下词条。
2. **阅读内容**：用 `read` 打开词条原文，提取正文回答用户问题。正文中的图片会以 `[图片: 说明](url)` 形式给出，表格会转为文本表格。
3. **时效问题**：同一主题（如校历、考试安排）通常有多个学年版本，回答时优先引用最新版本；旧版本仅作参考。
4. **回答时给出出处**：引用词条时附上 wiki 原文链接，方便用户核对。

## 常见分类速查

- 招生: `招生简章` / `录取分数线与招生计划` / `录取通知书`
- 入学: `报到流程` / `报到/迎新` / `军训` / `入学考试` / `天麟班` / `新生周安排`
- 学籍: `党团关系及档案户口` / `贫困资助` / `主修专业确认` / `转专业` / `辅修`
- 学习: `校历` / `课程` / `成绩制度` / `考试安排` / `图书馆` / `自习室` / `等级考试与证书`
- 培养: `本科生培养计划` / `研究生培养方案` / `特殊培养类型班级` / `未来技术学院(求是学部)`
- 深造: `推免与优异生` / `考研` / `出国与交流` / `科研竞赛`
- 生活: `学生宿舍及设施` / `食堂与餐饮店` / `医疗与心理健康` / `校园网(电脑与上网)` / `学生票` / `快递` / `洗澡与洗衣`
- 制度: `规章制度` / `奖学金(奖助励学金与贫困生制度)` / `挂科与试读` / `假期校园生活指南`

## 注意事项

- 站点对高频请求可能限流，连续操作之间稍作间隔。
- 若 `read` 输出为空或报错，改用 WebFetch 直接抓原文链接兜底。
- 部分页面（如 `/about`）可能返回 503，属站点限制，不影响主功能。
